Setting up your laptop

A one-off setup, about ten minutes. Claude does most of it for you.

You only do this once. Steps 1 and 2 are the two things only you can do, because they involve your own accounts. In step 3, Claude does the rest.

1. Install Claude Desktop

Download it from claude.com/download and sign in (or create an account).

You need a Claude Pro account (or a higher plan) to use Claude Code, the part of Claude Desktop that edits the website for you. A free account can chat, but it can't do this job.

2. Create a GitHub account

GitHub is the safe place where the website's files are kept, along with a record of every change ever made. Create a free account at github.com/join if you don't already have one.

Before you ask for access, switch on two-factor authentication (2FA) on your new account. This means GitHub asks for a short code from an app on your phone when you sign in, which keeps the account safe. In GitHub, go to Settings → Password and authentication → Two-factor authentication and follow the steps (an authenticator app is the easiest option). Access won't be granted to an account without it.

Once you have an account with 2FA switched on, email your GitHub username to web@mediawright.uk and ask to be added as a collaborator on the repository (the project). You won't be able to make changes until you've been added.

3. Let Claude do the rest

Open Claude Desktop and click the Claude Code icon, then start a new session. (Claude Code is the part that can work on your laptop and talk to GitHub for you. An ordinary chat can't.) Paste the box below in exactly as it is, type your GitHub username after "My GitHub username is:", and send it.

Claude will check your laptop, install anything that's missing, fetch the website's files, and tell you when it's ready. If it asks you to click something or approve something, that's normal.

The first time Claude connects to GitHub, a browser window may open asking you to sign in. That's expected, and it only happens once.

If anything confuses you, tell Claude. Describe what you see, for example "I got an error" or "it's asking me something I don't understand", and it will explain and help you through. Once it says it's ready, move on to Making a change.
