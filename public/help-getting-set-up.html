    Setting up your laptop

    A one-off, roughly ten-minute setup.

    1. Install Claude Desktop

    Download it from claude.com/download and sign in (or create an account).

    2. Create a GitHub account

    This site's source code lives on GitHub. Create a free account at github.com/join if you don't already have one.

    Before you request access, turn on two-factor authentication (2FA) on your new account: in GitHub, go to Settings → Password and authentication → Two-factor authentication and follow the setup steps (an authenticator app is the easiest option). GitHub collaborator access won't be granted to an account without it.

    Once you've got one and 2FA is switched on, email your GitHub account name to web@mediawright.uk and ask to be added as a collaborator on the repository — you won't be able to make changes until you've been given access.

    3. Ask Claude to set the rest up

    Open Claude Desktop's Code tab (also called Claude Code — it's what lets Claude read and edit files on your laptop and talk to GitHub on your behalf; an ordinary chat elsewhere in the app can't do either), paste the box below into it exactly as it is, and send it. Claude will check your laptop has what it needs, fetch a working copy of the website, and tell you when it's ready.

    The first time Claude needs to connect to GitHub on your behalf, a browser window may pop up asking you to sign in — that's expected, and only happens once. Once it's done, you're ready to make a change — see Making a Change.
